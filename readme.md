
# Aviation-Tool-TS

Find airport weather and distances to other airports within a time range.


## Set up locally and run

Clone the project

```bash
  git clone https://github.com/rainbowardite/aviation-tool-ts
```

Go to the project directory

```bash
  cd aviation-tool-ts
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```

## Build project

Install dependencies

```bash
  npm install
```

Build Project

```bash
  npm run build
```

Preview built project

```bash
  npm run preview
```
